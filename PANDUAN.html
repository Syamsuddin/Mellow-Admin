01. Menjalankan template

  1. Ekstrak ZIP sampai seluruh folder dan berkas terlihat.
  2. Buka index.html. Pertahankan folder assets di lokasi yang sama.
  3. Untuk satu berkas mandiri, buka Mellow-Admin-Standalone.html. CSS, ikon, dan React sudah tertanam.
  4. Gunakan menu sidebar atau dock bawah untuk berpindah halaman. Pada ponsel, buka tombol menu di kiri atas.

Hasil build tidak memakai CDN, font eksternal, atau API jaringan. Node.js hanya diperlukan saat mengubah dan membangun ulang sumber React.

Penyimpanan data

Data demo tersimpan di localStorage dengan kunci mellow-admin-v1. Data terpisah menurut peramban dan origin. Jika akses storage diblokir, perubahan bertahan selama sesi. Perilaku storage pada file lokal mengikuti peramban. Untuk pengujian konsisten gunakan server lokal:

python3 -m http.server 8080

Buka http://localhost:8080. Menu Settings menyediakan Reset demo data dengan konfirmasi.

Menggunakan kanban

  1. Klik New deal, isi formulir, lalu Save deal.
  2. Pada desktop, seret kartu ke kolom tahap tujuan.
  3. Pada ponsel atau keyboard, gunakan pilihan Move to pada kartu. Alternatifnya buka kartu lalu ubah Stage.
  4. Klik judul atau tombol tiga titik untuk mengedit. Tombol Delete membuka konfirmasi.
  5. My deals menampilkan pemilik MT, profil demo Mia Taylor. Filter ini bukan sistem autentikasi.

Papan kanban bergulir horizontal di layar kecil. Statistik dan formulir menyesuaikan lebar layar.

03. Angka dan data demo

Mata uang contoh adalah USD. Data awal menggunakan November 2026. Ringkasan dihitung dari daftar deal yang sedang difilter:

  • Open pipeline: jumlah nilai tahap New, Contacted, Proposal, dan Negotiation.
  • Weighted forecast: nilai setiap deal terbuka dikalikan probabilitas tahap.
  • Won deals: total seluruh deal pada tahap Won, tanpa filter bulan.
  • Average deal size: total nilai deal dibagi jumlah deal.

Probabilitas tahap: New 15%, Contacted 35%, Proposal 55%, Negotiation 75%, Won 100%. Angka awal: pipeline $258.500, forecast $126.875, Won $101.000, rata-rata $29.958,33. Format kartu membulatkan ke ribuan.

Grafik revenue menggunakan angka historis ilustratif. Invoice, kalender, dan tugas memiliki data contoh masing-masing. Ketiganya tidak tersinkron otomatis dengan deal. Tidak ada email atau transaksi pembayaran yang dikirim dari template ini.

05. Integrasi PHP, Laravel, atau backend lain

Template berfungsi sebagai frontend. Backend, akun pengguna, pembatasan hak akses, dan database perlu dikembangkan terpisah.

  1. Letakkan index.html dan assets pada direktori publik aplikasi atau hosting statis. URL halaman menggunakan hash, seperti #deals, sehingga tidak memerlukan rewrite khusus.
  2. Ganti pembacaan seed/localStorage dengan API backend.
  3. Hubungkan fungsi saveRecord, patch, move, dan remove ke endpoint server. Fungsi remove langsung menghapus lalu menawarkan Undo, jadi panggil DELETE setelah toast Undo berakhir atau sediakan endpoint pemulihan.
  4. Tambahkan status loading, pesan kegagalan, pembatalan permintaan, serta rollback ketika server menolak perubahan.
  5. Terapkan autentikasi, validasi ulang, dan otorisasi setiap operasi di server. Untuk cookie session, sertakan perlindungan CSRF.
  6. Simpan kredensial database pada konfigurasi server. Jangan menaruh rahasia di bundle frontend.

Contoh kontrak endpoint berikut merupakan rancangan integrasi. Endpoint belum dibuat di paket:

GET    /api/deals
POST   /api/deals
PATCH  /api/deals/{id}
DELETE /api/deals/{id}
GET    /api/contacts
GET    /api/tasks
GET    /api/events
GET    /api/reports/pipeline

Nilai transaksi sebaiknya disimpan sebagai DECIMAL pada MySQL atau bilangan satuan terkecil di server. Hubungkan grafik historis ke hasil agregasi server saat mengganti data demo.

06. Distribusi dan pemecahan masalah

Untuk hosting, unggah isi folder dist atau index.html bersama assets. Sumber React dan node_modules tidak diperlukan untuk menampilkan hasil build.
